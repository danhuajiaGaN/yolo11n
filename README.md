# YOLO11n Object Detection Demo
YOLO11n 目标检测示例项目

## Project Introduction / 项目介绍
This repository contains simple inference, training, validation and model export code based on YOLO11n from Ultralytics.
本仓库基于 Ultralytics 框架，提供 YOLO11n 的推理、训练、验证、模型导出简易代码，适合入门学习、测试目标检测流程，支持后续向 FPGA 平台部署。
